# 控制工程助手（微信小程序）

面向《自动控制原理》课程的计算与仿真小程序，所有计算都在本地用纯 JavaScript 完成，不需要服务器。

## 功能

| 页面 | 内容 |
| --- | --- |
| 时域响应 | 输入传递函数，绘制阶跃 / 脉冲 / 斜坡响应；给出极点、零点、稳定性、直流增益，以及上升时间、峰值时间、超调量、调节时间（2%）等指标 |
| 二阶系统 | 拖动 ζ、ωn 实时观察阶跃响应和 s 平面极点，理论公式与仿真结果对照，可叠加 ζ = 0.1 ~ 2 的曲线 |
| PID 仿真 | 设定被控对象，滑条实时调节 Kp / Ki / Kd（微分带滤波 N），显示闭环输出和控制量、超调量、调节时间、稳态误差、IAE / ITAE、闭环极点 |
| 频域分析 | Bode 图（幅频、相频）、奈奎斯特图，幅值裕度、相角裕度、截止频率、相位穿越频率、闭环稳定性 |
| 根轨迹 | 根轨迹图与渐近线、分离/会合点、与虚轴交点及临界增益、出射/入射角、闭环稳定的 K 范围；拖动 K 查看闭环极点 |
| 劳斯判据 | 自动列劳斯表，处理“首元素为零（ε 法）”和“全零行（辅助多项式）”两种特殊情况，给出右半平面根个数 |

所有图表都可以点按或拖动来读数。

## 多项式输入格式

两种写法都可以：

- 系数列表（降幂）：`1 3 2`、`1,3,2`
- 关于 s 的表达式：`s^2+3s+2`、`(s+1)(s+2)`、`10(0.5s+1)`、`s(s+1)^2`

中文标点（全角括号、逗号等）会被自动转换。

## 运行

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. “导入项目”，目录选择本仓库根目录。
3. AppID：`project.config.json` 中默认是 `touristappid`（测试号模式，可以预览）；要真机发布，请换成你自己的 AppID。
4. 基础库需 ≥ 2.9.0（使用 `canvas type="2d"`）。

## 算法说明

- **时域仿真**：传递函数转为可控标准型状态空间，用矩阵指数做零阶保持离散化，阶跃输入下是精确解（没有数值积分误差）。斜坡响应按 G(s)/s 的阶跃响应计算，脉冲响应取初始状态 x(0) = B。
- **相频特性**：按零极点逐项累加相角再做相位展开，保证曲线连续，起点相位正确。
- **裕度**：在对数频率上二分细化 |G(jω)| = 1 的截止频率；相位穿越点取相位穿过 −180° + k·360° 的位置。
- **根轨迹**：在对数 K 网格上求闭环特征根，相邻两组根贪心匹配，根移动过大时自适应加密；临界增益由最大实部过零二分求得。
